How contrast is calculated

Uses WCAG 2.x relative luminance with sRGB linearization, then (L1 + 0.05) / (L2 + 0.05) where L1 is the lighter color. Large text means ~18pt regular or 14pt bold. UI / non-text covers icons, borders, and graphical objects (WCAG 1.4.11).
